## 🗺️ 学習フロー図

```
【Day 1】─────────────────────────────────────
│
├─ 事前準備（ツール確認）
│
├─ Step 1: GitHub 環境構築
│    └─ GitHub アカウント確認
│    └─ SSH キー生成・登録（パスワードレス）
│    └─ リポジトリ作成・クローン
│
└─ Step 2: Copilot で文書作成
     └─ Copilot Chat で README を生成
     └─ 仕様書・定義書を AI で下書き
     └─ /explain・インラインチャットを体験

【Day 2】─────────────────────────────────────
│
├─ Step 3: Skills & Agents の作成
│    └─ Skill（指揮者）が Agents（ワーカー）を束ねる構造を理解する
│    └─ 既存の Skill・Agent ファイルを読んで仕組みを把握する
│    └─ 自分で Skill と Agent を作る（ハンズオン）
│
└─ Step 4: 記事自動生成を実装
     └─ URL を入力させるスキルを実行
     └─ node scripts/generate-article.js を動かす
     └─ HTML 記事が output/ に生成される

【Day 3】─────────────────────────────────────
│
├─ Step 5: Git ワークフロー
│    └─ git add / commit / push を実践
│    └─ GitHub でプッシュを確認
│
└─ Step 6（発展）: テンプレート活用
     └─ 記事構成テンプレートを保存・切り替え
     └─ デザインテーマを変更
     └─ さらなる自動化アイデアに挑戦
```

## 📋 このプロジェクトで作るもの

### 完成イメージ

```
【入力】
セキュリティニュースの URL（例: https://www.cisa.gov/news-events/...）

    ↓ Copilot Skill が処理

【出力】
きれいにスタイリングされた HTML 記事ファイル
  - タイトル
  - 要約（日本語）
  - 重要ポイント（箇条書き）
  - 対策アクション
  - ソースリンク
```

### なぜセキュリティニュース？

- IT 担当者が日々チェックすべき情報を **自動で記事化** できる
- 英語の記事を **日本語で要約** して社内共有できる
- 実務でそのまま使える成果物になる

## ❓ 困ったときは

1. **VS Code の Copilot Chat を開く**（`Ctrl+Shift+I`）
2. 「〇〇の意味を教えて」「このエラーを直して」と日本語で聞く
3. それでも解決しない場合は `/explain` コマンドで選択したコードを解説させる
